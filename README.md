# Aplicación de Gestión de Tareas
Aplicación de gestión de tareas desarrollada en JavaScript. Permite registrar, consultar y organizar tareas mediante un identificador, título, descripción, fecha, prioridad, estado y responsable. El proyecto comienza trabajando desde consola y evoluciona progresivamente hacia una aplicación web interactiva.
